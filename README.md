# FALCONS AI

Futuristic JARVIS-inspired AI assistant.

## Stage 1 — Frontend

- Dark futuristic command center
- Animated FALCONS AI core
- Responsive desktop/mobile UI
- Conversation console
- Quick actions
- Browser voice input
- Local demo responses

## Project structure

```
FALCONS-AI/
├── frontend/
│   ├── index.html
│   └── assets/
│       ├── css/style.css

```

## Run locally

Open `frontend/index.html` in a modern browser, or use VS Code Live Server.
